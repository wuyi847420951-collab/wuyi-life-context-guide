# Wuyi Life Context Guide

一个通过 AI 对话逐步建立、深化和维护「人生上下文」的开放 Skill。

它默认引导用户生成 11 个 Markdown 文件，让 AI 逐渐理解用户的愿景、价值观、能力、行为节奏、环境、当前方向、关键关系、当下状态和人生故事。创作者或个体创业者还可以选择开启「事业表达层」，继续梳理定位、产品和内容。

## 主要能力

- 首次建档：从一个维度开始，不要求一次完成
- 维度深化：基于已有内容继续追问，不重复已知信息
- 校准更新：只处理发生变化的部分
- 周更快填：用约 3 分钟更新本周状态和焦点
- 月季校准：定期检查六维变化和方向偏差
- 自动合成：汇总已完成维度，并标注来源、缺失信息和 AI 推断
- 会话恢复：通过路径定位文件和 `.meta.md` 支持跨会话继续
- 历史留痕：修改已有文件前自动归档旧版本
- 可选事业表达：依次梳理定位、产品和内容，不改变核心 11 文件

## 隐私提醒

人生上下文可能包含关系、经济、健康、个人经历等敏感信息。

- 生成内容默认只应保存在用户自己的本地目录
- 不要把生成的个人文件提交到公开 Git 仓库
- 不要在未获得本人许可时分享他人的信息
- 项目根目录的 `.wuyi-life-context-guide.json` 只记录存储路径和 Skill 版本，不记录个人内容；Git 项目会将它排除在本地提交之外
- 本 Skill 不依赖外部 API，也不会主动发送用户数据

## 安装

下载或克隆本仓库，把整个 `wuyi-life-context-guide` 文件夹放入 AI 工具的 Skill 目录，并保留 `SKILL.md`、`references/`、`assets/`、`examples/` 和隐藏文件 `assets/templates/.meta.md`。

Codex 的常见安装位置：

```text
${CODEX_HOME}/skills/wuyi-life-context-guide/
```

未设置 `CODEX_HOME` 时，通常使用：

```text
~/.codex/skills/wuyi-life-context-guide/
```

不同 AI 工具的 Skill 目录和加载方式可能不同，请以对应工具的文档为准。运行时需要允许 AI 读取模板，并向用户确认的目标目录写入 Markdown 文件。

## 使用

安装后，可以直接对 AI 说：

```text
帮我建立一份人生上下文。
```

也可以使用这些表达：

- 帮我梳理价值观
- 我想重新聊一下当前渴望
- 更新我的本周状态
- 合成关于我
- 帮我梳理个人定位
- 梳理我的产品和内容方向

Skill 第一次启动时会先确认存储目录，并询问是否开启事业表达层。每次仍然只处理一个维度。

## 产出结构

```text
我的人生上下文/
├── 关于我.md
├── 内核/
│   ├── 精神与愿景.md
│   ├── 价值观与底线.md
│   ├── 能力与天赋.md
│   ├── 行为与节奏.md
│   └── 环境与资源.md
├── 方向/
│   ├── 当前渴望.md
│   └── 关键关系.md
├── 当下/
│   ├── 本周状态.md
│   └── 本周焦点.md
└── 传记/
    └── 我的故事.md
```

开启事业表达层后额外生成：

```text
我的人生上下文/
└── 事业表达/
    ├── 定位.md
    ├── 产品.md
    └── 内容.md
```

核心关系：

```text
人生上下文 → 定位 → 产品 → 内容 → 真实反馈 → 校准人生上下文
```

## 升级已有数据

从 1.0.0 升级时，Skill 只补充定位文件、状态字段和可选模板，不覆盖用户已有正文。更新任何已有产出前，旧版本会保存到 `历史/YYYY-MM-DD-HHmm/`。

## 兼容性

- 面向能够加载 Markdown Skill、读取文件并写入用户目录的 AI Agent
- 产出为 Markdown + YAML frontmatter
- 可在 Obsidian、Logseq、VS Code 等工具中读取
- 不依赖外部 API、数据库或网络服务
