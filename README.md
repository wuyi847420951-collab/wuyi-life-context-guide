# Wuyi Life Context Guide

一个通过 AI 对话逐步建立、深化和维护「人生上下文」的开放 Skill。

它会引导用户生成 11 个 Markdown 文件，让 AI 逐渐理解用户的愿景、价值观、能力、行为节奏、环境、当前方向、关键关系、当下状态和人生故事。

## 主要能力

- 首次建档：从一个维度开始，不要求一次完成
- 维度深化：基于已有内容继续追问，不重复已知信息
- 校准更新：只处理发生变化的部分
- 周更快填：用约 3 分钟更新本周状态和焦点
- 自动合成：把已完成维度汇总为 `关于我.md`
- 会话恢复：通过 `.meta.md` 记录进度，支持中断后继续

## 隐私提醒

人生上下文可能包含关系、经济、健康、个人经历等敏感信息。

- 生成内容默认只应保存在用户自己的本地目录
- 不要把生成的个人文件提交到公开 Git 仓库
- 不要在未获得本人许可时分享他人的信息
- 本 Skill 不依赖外部 API，也不会主动发送用户数据

## 安装

下载或克隆本仓库，把整个 `wuyi-life-context-guide` 文件夹放入 AI 工具的 Skill 目录，并保留 `SKILL.md`、`references/`、`assets/`、`examples/` 和隐藏文件 `assets/templates/.meta.md`。

Codex 的常见安装位置：

```text
${CODEX_HOME}/skills/wuyi-life-context-guide/
```

未设置 `CODEX_HOME` 时，通常使用：

```text
~/.codex/skills/wuyi-life-context-guide/
```

不同 AI 工具的 Skill 目录和加载方式可能不同，请以对应工具的文档为准。运行时需要允许 AI 读取模板，并向用户确认的目标目录写入 Markdown 文件。

## 使用

安装后，可以直接对 AI 说：

```text
帮我建立一份人生上下文。
```

也可以使用这些表达：

- 帮我梳理价值观
- 我想重新聊一下当前渴望
- 更新我的本周状态
- 合成关于我

Skill 第一次启动时会先确认存储目录，然后只引导一个维度。

## 兼容性

- 面向能够加载 Markdown Skill、读取文件并写入用户目录的 AI Agent
- 产出为 Markdown + YAML frontmatter
- 可在 Obsidian、Logseq、VS Code 等工具中读取
- 不依赖外部 API、数据库或网络服务
