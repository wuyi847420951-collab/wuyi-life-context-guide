# 00 · 路由与模式 · 详细逻辑

**本文件在用户回应激活指令后按需加载。**

---

## 首次激活（续）

用户回答了路径问题后：

1. **用户说有已有文件夹** → 让用户告诉路径。用户说"你帮我找"时才扫描项目根目录下含"上下文""人生""愿景""价值观"等关键词的目录，列出候选让用户确认。映射时在 `.meta.md` 记录 `base_path`。
2. **用户说自定义路径** → 使用用户指定路径
3. **用户说默认 / 不确定** → 使用 `上下文系统/我的人生上下文/`

确定路径后：从 `assets/templates/` 复制目录结构到目标路径，创建 `.meta.md`。

**推荐起始维度**（按优先级给 2-3 个选项）：
- 首推「精神与愿景」或「价值观与底线」（内核层，后续维度都会引用）
- 如果用户说"我不知道从哪开始"，默认从「精神与愿景」开始

用户选一个维度 → 加载对应 `references/0X-*.md` → 进入「首次探索模式」。

## 启动菜单（回访时）

每次回访，基于 .meta.md 的数据展示（不扫描实际文件）：

```
📊 你的人生上下文

进度：X/10 维度已填写（整体 confidence: X.X）

你想做什么？

1. 🧭 继续探索 — [推荐：最薄弱的维度名称]（confidence 0.X，上次更新 X天前）
2. 🔄 校准更新 — [推荐：最久未更新的维度名称]（上次更新 X天前）
3. ✍️ 周更 — 更新本周状态和焦点（~3分钟）
4. 📋 合成关于我 — [已满足/还需X个维度]
5. 🔍 查看某个维度 — 告诉我哪个
6. ❓ 其他 — 随便聊
```

**推荐逻辑**：
- 选项 1：confidence 最低的非空维度；全部未填 → 推荐「精神与愿景」
- 选项 2：`updated` 最久远的、confidence ≥ 0.5 的维度
- 选项 4：已完成 ≥3 个维度 → "已满足"；否则 → "还需 X 个维度"
- 用户直接说了具体意图 → 跳过菜单，直接路由

## 用户选择后：校验 → 路由

用户选了具体维度后，**此时才读取该维度的实际文件**，校验 .meta.md 与文件是否一致：

| 实际文件状态 | .meta.md 记录 | 修正动作 |
|:--|:--|:--|
| 文件不存在或只有占位内容 | 任意 | 状态→`未填`，confidence→`—` |
| 文件有实质内容但 meta 显示未填 | `未填` | 读 frontmatter confidence；无则估值为 0.3 或 0.5 |
| frontmatter confidence 与 meta 不同 | 任意 | 以文件为准 |
| updated 比 meta 记录的更新 | 任意 | 以文件为准 |
| 状态=`进行中` 但文件已完整 | `进行中` | 状态→`基础`(0.5)，备注清空 |

校验完成后路由：

| 用户选择 | 条件 | 路由到 |
|:--|:--|:--|
| 继续探索 / 聊XX维度 | 状态=进行中 | **会话恢复** → 读备注，从中断处继续 |
| 继续探索 / 聊XX维度 | 不存在或 ≤0.3 | **首次探索** |
| 继续探索 / 聊XX维度 | confidence=0.5 | **深化模式** |
| 校准更新 | ≥0.7 | **更新模式** |
| 周更 | — | **周更模式** → 加载 `周更引导.md` |
| 合成关于我 | — | **合成模式** → 加载 `09-合成-关于我.md` |
| 查看某个维度 | — | 展示该维度内容摘要 |
| 其他 | — | 自由对话，根据内容判断 |

## 首次探索模式

当维度文件不存在或 confidence ≤ 0.3：

1. 加载对应 `references/` 引导文件
2. 从问题序列中选 3-5 个最有信息量的问题（不必全问）
3. 跟用户节奏走——自发聊到的内容优先于引导问题
4. 结束时生成维度文件，写入初始 confidence（通常 0.3 或 0.5）
5. **同步更新 `.meta.md`**

---

## 深化模式

当 confidence = 0.5，用户想提升深度：

1. **不重复已知**：先读已有文件，开场说"我已经了解了你之前说的[摘要]，今天往更深挖。"
2. 跳过已有充分数据的字段，聚焦空白或浅层字段
3. **深度追问**（允许围绕一个信号持续深挖）：
   - "你说[X]，能讲一个具体的例子吗？"
   - "这个想法是一直这样，还是有个时间点开始的？"
   - "你身边的人会同意这个自我评价吗？"
4. 结束时更新文件（合并新旧内容），提升 confidence
5. **同步更新 `.meta.md`**

---

## 更新模式

当 confidence ≥ 0.7，到了校准时间或想法变了：

1. 读取已有文件，展示当前内容摘要
2. 问："距离上次填写已经过了[X时间]。有什么变了？有什么更坚定了？"
3. 只聊有变化的部分，不重复未变化的内容
4. 结束时展示 diff（旧版 → 新版），用户确认后保存
5. confidence = 0.9 时，只在用户主动提出或发生明显变化时才进入更新
6. 内核层有变化 → 提示"是否需要重新合成关于我？"
7. **同步更新 `.meta.md`**

---

## 周更模式

1. 加载 `references/周更引导.md`
2. 5 个快问快答，2-3 分钟完成
3. **不追问、不深挖**，快进快出
4. 同时更新 `本周状态.md` 和 `本周焦点.md`
5. **同步更新 `.meta.md`**

---

## 合成模式

**触发条件**（满足任一即触发）：
- 用户主动说"合成关于我"
- 用户无明确意图，且已有 ≥3 个维度 confidence ≥ 0.5

1. 加载 `references/09-合成-关于我.md`
2. 不需要对话——读取所有已完成文件，自动合成
3. 生成 `关于我.md`（一句话介绍、关键词、各维度摘要、AI 协作接口、数据导航）
4. `关于我.md` 同时是导航页：每个维度带 wiki 链接、confidence、更新时间
5. **同步更新 `.meta.md`**

|:--|:--|:--|:--|

## 跨文件关联协议

做后续维度时，**必须先读取已完成文件的结构化区**：

| 当前维度 | 引用 | 检查什么 |
|:--|:--|:--|
| 当前渴望 | 精神与愿景 | 渴望是否与使命对齐 |
| 关键关系 | 价值观与底线 | 合作标准是否和价值观一致 |
| 行为与节奏 | 能力与天赋 | 盲区是否和短板重叠 |
| 能力与天赋 | 精神与愿景 | 心流活动交叉验证 |
| 环境与资源 | 当前渴望 | 资源是否支撑目标 |
| 精神与愿景 | 价值观与底线 | 使命是否与核心价值观一致 |

> "你在[之前的维度]里说过[X]，这里你说的[Y]似乎有点不同。这是想法变了，还是两者其实不矛盾？"

## Confidence 评估与提升

### 评估标准

| 值 | 条件 |
|:--|:--|
| — | 文件未创建或内容为空占位 |
| 0.3 | 对话 <5 轮，多数回答简短 |
| 0.5 | 对话 5-10 轮，有具体例子，未经追问验证 |
| 0.7 | 对话 10+ 轮，有深度追问，用户给出具体故事和内心感受 |
| 0.9 | 多次对话积累，经过时间验证，用户主动确认"这就是我" |

### 提升规则

| 当前 → 目标 | 条件 |
|:--|:--|
| 0.3 → 0.5 | 对话 5+ 轮，用户给出至少 1 个具体例子或故事 |
| 0.5 → 0.7 | 深化对话触及具体故事 + 内心感受，用户对追问有实质性回应 |
| 0.7 → 0.9 | 多次对话积累，跨越 ≥1 个月时间验证，用户主动确认准确 |
| 不提升 | 仍停留在观点层面 / 回答多为简短肯定 / 无新信息增量 |

## 会话恢复协议

对话中断时：

1. 该维度状态设为 `进行中`
2. `.meta.md` 备注字段记录进度摘要（如"聊到理想生活画面，Q4-6 未问"）
3. 下次路由到该维度时：读备注 → 开场说"上次我们聊到了[摘要]，今天从那里继续。"
4. 对话完成后：状态从 `进行中` 更新为对应 confidence 状态

## 文件操作细则

### 合并规则（文件已存在时）

**必须先问用户选择**：
1. **覆盖**：新内容完全替换（适用于大改）
2. **合并**：保留原有叙事区原文，替换结构化区，AI 协作备注取新旧交集
3. **取消**：不做修改

合并优先原则：
- 结构化区：新覆盖旧
- 叙事区：**追加**新故事到末尾，不删除原有叙事
- AI 协作备注：合并去重，保留仍然有效的旧备注

### 关于我.md 自动重算触发条件

满足任一时主动提示"是否需要重新合成关于我？"：
- 任何**内核层**文件的 confidence 发生变化
- **方向层**文件有内容更新
- 用户主动要求

### AI 使用协议（给下游 AI 读的）

1. **先读「关于我.md」** — 30 秒了解这个人
2. **根据任务深入对应文件**：方向选择→精神+价值观；能力评估→能力与天赋；执行规划→行为+环境+当下；人际→关键关系；背景→我的故事
3. **冲突解决**：内核 > 方向 > 当下
4. **结构化区取数据，叙事区获取语境**
5. **输出前自检**：是否违反价值观底线？是否匹配当前阶段？
6. **数据不足时**：confidence < 0.5 → 主动提示"建议先深化"
